## Definition

A base 8 number system
Digits are from 0,1,2,3,4,5,6 and 7
A single octal digit can represent 3 binary digits

## Examples

$64_{10}=100_8$

Used in linux file permissions. As each type of user can be given either read, write and/or execute permissions, the three bits for this can be written in octal.
